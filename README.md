# 時給計算機

## 概要

時給と労働時間を入力するだけで、1日の給与・残業代・月給・年収を計算するWebアプリです。
残業代には法定の割増率25%を適用します。

※ 深夜割増・休日労働などは考慮していない概算用のツールです。実際の給与は就業規則や36協定などに従ってください。

## 機能

- 時給・通常労働時間（1日あたり、時間・分）・残業時間（1日あたり、時間・分）・月の労働日数を入力
- 入力するたびに自動で再計算し、次の4項目を表示
  - 1日の給与（通常分 ＋ 残業分）
  - 残業代（1日分。時給 × 1.25 × 残業時間）
  - 月給（1日の給与 × 月の労働日数）
  - 年収（月給 × 12）
- 金額は円単位に四捨五入し、3桁区切りで表示
- 入力チェック（0以上の整数か、分は0〜59か）。エラーは操作した項目についてのみ表示
- モバイル対応のレスポンシブデザイン

## 使用技術

- HTML
- CSS（カスタムプロパティ / CSS Grid / メディアクエリ）
- JavaScript（フレームワーク不使用のバニラJS）
- `toLocaleString('ja-JP')` による金額表示
- デプロイ: Cloudflare Pages
